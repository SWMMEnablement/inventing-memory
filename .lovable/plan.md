
# Hallucinating Hopfield — a self-rewriting memory

A single-page interactive piece. A Hopfield network is trained on a small alphabet of bitmap glyphs. The user watches memories decay in real time: noise is injected into the weight matrix, the network is re-queried, and the attractors drift into glyphs that were never taught. Forgetting becomes invention.
